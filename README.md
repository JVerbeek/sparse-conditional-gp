# Code accompanying the paper *Sparse conditional Gaussian processes*
This code implements the experiments in the paper *Sparse conditional Gaussian processes*, submitted to AISTATS 2027. The code relies heavily on [GPFlow](https://gpflow.github.io/GPflow/2.9.1/index.html); some basic familiarity with it is therefore useful, but otherwise the linked page has great tutorials. y

## Getting started 
In order to use the code, use your favorite virtual environment manager to install `requirements.yml` in a clean environment. With Conda, for instance, this is done as follows:
```python
conda env create --file requirements.yml --name myname
conda activate myname
```
We supply an additional file for MacOS (`requirements-macos-arm64.yml`), which is required for Tensorflow to work.

## Usage
A relatively minimal working example of the sparse conditional Gaussian process with 20 inducing variables is the following cell:
```python
from atmodel import SparseCMOGP
from atlikelihood import TransferLikelihood
from inducing_variable import LMCInducingPointsBase
import gpflow as gpf
import numpy as np

N = 1000
output_dim = 2
rank = 1
nIVS = 20

gk1, gk2 = gpf.kernels.RBF(lengthscales=0.2), gpf.kernels.RBF(lengthscales=0.8)
X1 = np.linspace(-1, 1, N).reshape(-1, 1)
X2 = np.linspace(-1, 1, N).reshape(-1, 1)
y1 = (np.random.multivariate_normal(np.zeros((N,)), gk1(X1)) + np.random.normal(0, 0.05, N)).reshape(-1, 1)
y2 = (np.random.multivariate_normal(np.zeros((N,)), gk2(X2)) + np.random.normal(0, 0.1, N)).reshape(-1, 1)

X = np.vstack((np.hstack((X1, np.zeros_like(X1))), np.hstack((X2, np.ones_like(X2)))))
y = np.vstack((np.hstack((y1, np.zeros_like(y1))), np.hstack((y2, np.ones_like(y2)))))
k = gpf.kernels.Matern32(active_dims=[0])
coreg = gpf.kernels.Coregion(output_dim=output_dim, rank=rank, active_dims=[1])

kern = k * coreg

ivs = np.linspace(np.min(X[:,0]), np.max(X[:,0]), nIVS).reshape(-1, 1)
iv_ind = [j * np.ones((int(nIVS/output_dim), 1)) for j in range(output_dim)]
iv_ind = np.concatenate(iv_ind) 
ivs = ivs[np.random.permutation(np.arange(len(ivs)))]
ivs = np.hstack((ivs, iv_ind))

scmogp_ivs = LMCInducingPointsBase(ivs)

model = SparseCMOGP((X, y), kernel=kern, inducing_variable=scmogp_ivs, likelihood=TransferLikelihood(source=gpf.likelihoods.Gaussian(), target=gpf.likelihoods.Gaussian()))

gpf.optimizers.Scipy().minimize(model.training_loss, model.trainable_variables)
fmean, fvar = model.predict_f(X)

```
We also have a GPFlow implementation of the model by [Cao et al. (2010)](https://ojs.aaai.org/index.php/AAAI/article/view/7682/7543), which can be used as follows,
```python
from atmodel import ConditionalMOGP
from atlikelihood import TransferLikelihood
import gpflow as gpf
import numpy as np

N = 200
output_dim = 2
rank = 1

gk1, gk2 = gpf.kernels.RBF(lengthscales=0.2), gpf.kernels.RBF(lengthscales=0.8)
X1 = np.linspace(-1, 1, N).reshape(-1, 1)
X2 = np.linspace(-1, 1, N).reshape(-1, 1)
y1 = (np.random.multivariate_normal(np.zeros((N,)), gk1(X1)) + np.random.normal(0, 0.05, N)).reshape(-1, 1)
y2 = (np.random.multivariate_normal(np.zeros((N,)), gk2(X2)) + np.random.normal(0, 0.1, N)).reshape(-1, 1)

X = np.vstack((np.hstack((X1, np.zeros_like(X1))), np.hstack((X2, np.ones_like(X2)))))
y = np.vstack((np.hstack((y1, np.zeros_like(y1))), np.hstack((y2, np.ones_like(y2)))))

k = gpf.kernels.Matern32(active_dims=[0])
coreg = gpf.kernels.Coregion(output_dim=output_dim, rank=rank, active_dims=[1])

kern = k * coreg

model = ConditionalMOGP((X, y), kernel=kern, likelihood=TransferLikelihood(source=gpf.likelihoods.Gaussian(), target=gpf.likelihoods.Gaussian()))

gpf.optimizers.Scipy().minimize(model.training_loss, model.trainable_variables)
fmean, fvar = model.predict_f(X)
```

## How to obtain the figures in the paper
All the code used to generate the results and figures/tables in the paper is present in this repository. Below, we provide a list of the figures and tables in our paper, how to obtain the necessary results to generate them, and where the code used to generate the figures and tables lives.

- Figure 1 Generated in `synthetic-data/motivating-example.ipynb`.
- Figure 2: `synthetic-data/target5/dataset-0-sparse.png` (generated by running synthetic-data.py with proportion 0.05)
- Figure 3: `synthetic-data/analysis.ipynb` (results generated by running `python3 synthetic-data/synthetic-data.py`, runs with proportion 0.05 by default; running synthetic-data.py 0.5 runs the experiment with proportion 0.5. Results can thus be obtained by running with argument 0.1, 0.2, 0.5). 
- Figure 4: `empirical-complexity/analysis.ipynb` (results generated by running, for example, `python3 speedtest-script.py SVGP fixed` or `python3 speedtest-script.py sCMOGP variable`)
- Figure 5: result of running `python3 soil-moisture/soil_transfer_learning.py`, figure can be found in `soil-moisture/plots-paper/04_01/target_50IVS.png'
- Figure 6: result of running `python3 snow-swe/fit_conditional.py`, figure can be found in `snow-swe/figures/perturbed-normal.png`.
- Figure 7: generated in `synthetic-data/kernel-example-appendix.ipynb`.
- Figure 8: result of running `python3 soil-moisture/Wageningen/eda/eda_soil_moisture.py`, figure can be found in `soil-moisture/Wageningen/eda/figures/fig5_5cm_interstation_correlation.png`.
- Figure 9: result of running ` python3 soil-moisture/Wageningen/eda/eda_soil_moisture.py`, Underlying map was made using a [Plotly scattermap](https://plotly.com/python/tile-scatter-maps/) via a different virtual environment, as Plotly required a version of `numpy` that conflicted with the one needed for GPFlow. Code can be found in `soil-moisture/Wageningen/eda/eda_soil_moisture.py`, a similar figure can be found in `soil-moisture/Wageningen/eda/figures/fig7_station_map.png`, just without the underlying map.
- Figure 10(a/b/c/d): result of running `soil-moisture/Wageningen/eda/eda_soil_moisture.py`, figures can be found in `soil-moisture/Wageningen/eda/figures/crossdepth`. Figures in the paper correspond to `fig6_{1, 7, 10, 15}_correlation.png` in that directory.
Table 1: Results for table can be obtained by running the notebook `soil-moisture/analysis.ipynb`; relevant results are written to results after running `python3 experiments/soil-moisture/soil_transfer_learning.py 0`, `python3 experiments/soil-moisture/soil_transfer_learning.py 1`, `python3 experiments/soil-moisture/soil_transfer_learning.py 2` and `python3 experiments/soil-moisture/soil_transfer_learning.py 3`  
Table 2: Results for table can be obtained by running the notebook `snow-swe/analysis.ipynb`; relevant results are written to `results` after running `python3 fit_conditional.py`.
